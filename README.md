# 소비요정 · 소비의 순간, 한 박자

> 사기 전 3초, 소비 성향별 요정이 먼저 물어봐요.
> AI DESIGN FOUNDATION 01 · TEAM 05

설문으로 나만의 소비 요정 한 명이 정해져요. 그 요정이 내가 고른 쇼핑 앱을 열 때, 장바구니에 담을 때, 결제 버튼을 누를 때 나타나 질문을 건네요.
결제를 막지 않고 구매 · 보류 · 제외 중 하나를 고르게 하고, 그 결정은 소비 기록과 요정의 상태 · 레벨로 쌓여요.

| 요정 | 유형 | 나타나는 순간 |
| --- | --- | --- |
| 토닥이 | 감정 전환형 | 앱을 열 때 기분 묻기 · 장바구니 · 결제 직전 |
| 멈칫이 | 즉시 구매형 | 앱을 열 때 · 결제 직전 “언제 쓸 거야?” |
| 쏙담이 | 연쇄 구매형 | 처음 살 것 기억하기 · 장바구니 · 결제 직전 |
| 곰곰이 | 혜택 반응형 | 앱을 열 때 · 무료배송 조건 채우기 · 결제 직전 |
| 쉬엄이 | 습관 반복형 | 앱을 연 횟수 · 탐색 시간 타이머 · 결제 직전 |

### 주요 기능
- **소비 계획 추천**: 한 달 수입과 고정 지출을 적으면 유형에 맞춰 저금 · 식비 · 생활 · 쇼핑 · 여유 비율을 추천하고, 쇼핑 예산을 정해줘요.
- **요정 탄생 연출**: 저금통에 동전이 들어가고 → 알이 나타나 → 깨어나며 나만의 요정이 태어나요.
- **내 요정**: 쓰다듬기, 말 걸기(음성 인식 · 글), 내 말을 귀여운 목소리로 따라 하는 ‘따라하기’, 코인으로 리본 · 왕관 · 배경 꾸미기.
- **기운과 회복 미션**: 예산을 넘거나 즉흥 구매가 쌓이면 기운이 줄고, 회복 미션(질문에 답하기, 무지출 데이, 7일 연속 등)으로 다시 회복해요.
- **소비 기록**: 주간 예산과 연속 기록(스트릭), 예산을 지킨 달의 월간 메달, 예산 80% · 100% 알림, 환불 · 교환 · 되팔기 반영.

> 음성 대화는 마이크를 쓸 수 있는 브라우저(GitHub Pages 주소의 Chrome · Safari, 안드로이드 앱)에서 동작해요.

## 1. 웹앱 공개하기 (GitHub Pages) — 처음 한 번

1. 저장소 **Settings → Pages**로 가요.
2. **Source**: `Deploy from a branch`, **Branch**: `main`, 폴더 `/docs`를 고르고 **Save**를 눌러요.
3. 1~2분 뒤 아래 주소에서 앱이 열려요.
   `https://djws1201-sketch.github.io/aibasicdesign/`

---

## 2. 아이폰에서 쓰기

아이폰은 다른 앱 화면 위에 캐릭터를 띄우는 기능을 애플이 허용하지 않아요. 대신 **단축어 자동화**로, 쇼핑 앱을 열면 요정 화면이 먼저 뜨게 연결해요.

1. 아이폰 **Safari**에서 위 주소를 열고 설문을 마쳐요.
   (기록이 한곳에 모이도록 홈 화면 아이콘 대신 Safari에서 열어 주세요.)
2. 앱의 **전체 → 아이폰 단축어로 쇼핑 앱 연결**로 가서 쇼핑 앱별 주소를 복사해요.
3. **앱을 열 때 요정 부르기**
   단축어 앱 → 자동화 → `+` → 앱 → 쇼핑 앱 선택 · **열려 있을 때** · **즉시 실행** → 새로운 빈 단축어 → **URL 열기** → 복사한 주소를 붙여넣어요.
4. **결제 직전에 요정 부르기 (뒷면 탭)**
   단축어 앱에서 `URL 열기`(결제 직전 주소) 하나만 있는 단축어 ‘요정 부르기’를 만들어요. 설정 → 손쉬운 사용 → 터치 → **뒷면 탭** → **이중 탭**에 연결해요. 결제 버튼 앞에서 휴대폰 뒷면을 톡톡 두 번 치면 요정이 나와요.
5. 요정과 대화를 마치면 화면 왼쪽 위의 **◀ 쇼핑 앱 이름**을 눌러 돌아가요.

## 3. 안드로이드에서 쓰기 (쇼핑 앱 위에 요정이 직접 나타나요)

### APK 받기
- `main`에 올릴 때마다 GitHub Actions가 APK를 자동으로 만들어요.
- 저장소 오른쪽 **Releases → 소비요정 Android 앱 (최신)** 에서 `sobiyojeong.apk`를 휴대폰으로 내려받아요.
- 빌드 진행 상황은 **Actions** 탭에서 볼 수 있어요. 첫 빌드는 5분쯤 걸려요.

### 설치와 권한
1. 내려받은 APK를 열어 설치해요. 출처를 알 수 없는 앱 설치를 허용하라는 안내가 나오면 허용해요.
2. 소비요정 앱을 열고 **함께할 쇼핑 앱**(휴대폰에 설치된 앱 목록)을 고른 뒤 설문을 마쳐요.
3. **접근성 서비스**를 켜요: 설정 → 접근성 → 설치된 앱 → **소비요정 쇼핑 감지** → 사용.
   - **스위치가 회색이라 안 켜지면** (Android 13 이상): 설정 → 애플리케이션 → 소비요정 → 오른쪽 위 `⋮` → **제한된 설정 허용** → 다시 접근성에서 켜요.
4. 고른 쇼핑 앱을 열면 요정이 화면 오른쪽 아래에 나타나요.

### 요정이 알아채는 순간
| 순간 | 어떻게 알아채나요 |
| --- | --- |
| 쇼핑 앱을 열 때 | 고른 앱이 화면 앞으로 나오는 순간 |
| 장바구니에 담을 때 | ‘장바구니’, ‘담기’ 버튼을 누른 순간 |
| 결제 직전 | ‘결제’, ‘구매하기’, ‘바로 구매’, ‘주문하기’ 버튼을 누른 순간 |

- 결제 직전에 **보류**나 **제외**를 고르면 “결제 화면에서 나갈까?”라고 물어보고, 원하면 뒤로 가기를 대신 눌러줘요.
- 쉬엄이는 정한 탐색 시간이 지나면 다시 나타나고, ‘여기까지 볼래’를 고르면 홈 화면으로 보내줘요.
- 요정과의 결정은 소비요정 앱을 다시 열 때 소비 기록 · 다시 볼 상품 · 레벨에 반영돼요. 금액은 소비 기록에서 적을 수 있어요.

### 개인정보
접근성 서비스는 버튼 글자를 읽어 순간을 알아채는 데만 쓰고, 화면 내용을 저장하거나 밖으로 보내지 않아요. 모든 기록은 휴대폰 안에만 저장돼요.

## 참고
- 쇼핑 앱마다 버튼 이름이 달라서, 일부 앱에서는 장바구니 · 결제 순간을 못 알아챌 수 있어요. `YojeongService.java`의 `CHECKOUT`, `CART` 패턴에 버튼 글자를 추가하면 돼요.
- 체험용 쇼핑몰(앱 안의 ‘쇼핑 앱 열기’)은 실제 쇼핑 앱 없이 시연할 때 써요.
- 이 앱은 수업 프로젝트용 프로토타입이에요. Play 스토어에 올리려면 접근성 API 사용 정책 심사가 필요해요.
